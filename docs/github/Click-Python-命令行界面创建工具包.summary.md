# Click：Python 命令行界面创建工具包

> 原文: https://github.com/pallets/click
> 来源: github · 生成时间: 2026-09-16T11:23:04.204969+00:00

## 一句话概括

Click 是一个用少量代码以可组合方式创建美观命令行界面的 Python 包，提供合理默认值且高度可配置。

## 关键要点

- Click 是 Python 的命令行界面创建工具包，以可组合方式用最少代码构建 CLI。
- 支持命令的任意嵌套、自动生成帮助页面以及运行时惰性加载子命令。
- 提供高度可配置性，同时开箱即用，带有合理的默认设置。
- 旨在让编写命令行工具快速有趣，避免无法实现预期 CLI API 的挫败感。
- 由 Pallets 组织开发维护，接受捐赠并欢迎社区贡献。
